# Discord Token Grabber

## Installation
This project does not require any installation. The code can be run directly on a Windows system.

## Usage
The Discord Token Grabber is a Python script that can be used to extract Discord tokens from various locations on the user's system. The script will then send the extracted tokens, along with additional user information, to a specified Discord webhook.
